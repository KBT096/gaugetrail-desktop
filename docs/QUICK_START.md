# GaugeTrail Desktop 快速上手

- 作者：KBT096
- 版本：v0.1.1

## 1. 下载与启动

1. 打开 [最新 Release](https://github.com/KBT096/gaugetrail-desktop/releases/latest)；
2. 下载 `GaugeTrail-Desktop-v0.1.1-win-x64.zip`；
3. 解压到任意可写目录；
4. 双击 `GaugeTrail.Desktop.exe`。

发布包为 Windows x64 自包含版本，不需要管理员权限，也不要求单独安装 .NET Runtime。

## 2. 先体验内置数据

首次启动自动载入“A 线 · 轴套外径”：

- 58 条测量记录；
- 三个演示批次；
- 一段平稳数据；
- 一段持续偏移；
- 一个特殊原因点。

先打开“过程总览”查看图表，再进入“规则信号”选择一条信号阅读证据。

## 3. 导入自己的 CSV

最小格式：

```csv
timestamp,value
2026-08-21 08:00:00,10.02
2026-08-21 08:20:00,10.08
```

完整格式：

```csv
timestamp,value,batch,source,note
2026-08-21 08:00:00,10.02,B-01,数字千分尺,首件复核
```

在“测量数据”页面点击“导入 CSV”，或把一个 `.csv` 文件直接拖进窗口。应用会让你选择替换或合并；错误行会单独列出。

## 4. 设置规格

进入“工作区设置”，填写：

- 工作区名称；
- 指标名称；
- 单位；
- LSL；
- Target；
- USL。

保存后，图表和过程能力会重新计算。规格限来自用户设置，控制限来自当前数据。

## 5. 建立行动项

1. 在“规则信号”选择一条记录；
2. 点击“为此信号创建行动项”；
3. 填写负责人；
4. 逐步推进状态；
5. 从“已采取措施”进入“待关闭”前填写验证备注。

## 6. 导出

“报告与导出”页面提供：

- CSV 测量数据；
- Markdown 过程快照；
- JSON 完整工作区。

默认工作区位于 `%LOCALAPPDATA%\GaugeTrail\workspace.json`。

## 7. 使用边界

GaugeTrail Desktop v0.1.1 是可运行 Demo，不是经过行业认证的产品放行系统。正式使用前，请由质量专业人员确认抽样方案、规则集、控制图类型和计量系统。
